# 🩸 Kan Hücresi Anomali Tespiti 2025

Bu proje, kan hücrelerinin morfolojik özelliklerini kullanarak anomali tespiti yapan bir makine öğrenmesi sistemidir.
Projede Random Forest, XGBoost, SVM algoritmaları kullanılmıştır.
Projem değerlendirme metrikleri olarak ise Accuracy, Precision, Recall, F1 kullanan bir sınıflandırma
algoritmasıdır.
